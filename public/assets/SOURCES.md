- `mark.svg`: newly drawn temporary brand mark retaining the supplied planning document's map pin, mountain and winding path ideas. Replace with official vector artwork when available.
- `display.ttf`: Noto Serif SC, weight 600, Google Fonts text subset for Chinese display headings, SIL Open Font License. Source: https://fonts.google.com/noto/specimen/Noto+Serif+SC and https://github.com/notofonts/noto-cjk . System Songti/serif handles characters outside the subset.

Icons are original inline SVG path geometry in app.js. No external icon runtime or CDN is required.
