村小丫 / SylvaPlan 聚焦乡村信息分散、旅行需求难以对应具体体验的问题。项目把需求表达、目的地匹配、餐饮住宿与活动选择、路线生成连接在一个工作台里。

表达需求 → 确认偏好 → 挑选乡村与体验 → 每日行程 → 保存与反馈

从信息展示，走向规划任务

这次界面更新以用户提供的 Mindtrip 工作台截图为布局参考：左侧持续导航，中间处理对话和规划，右侧保留地图。SylvaPlan 是村小丫的英文品牌；中英文切换保留表单、选择和用户原话。

地图展示城市范围，帮助建立目的地的地理概念。现有资料缺少经过核实的村落坐标，因此地图不提供村落精确位置或导航路线。

两种运行方式，一条任务流程

  • 数据库与模型模式：原有 Express / MySQL 后端保留会话、数据库匹配、餐饮住宿与活动选择、DeepSeek 标签解析和路线生成接口。模型失败时提供模板路线。
  • 便捷体验模式：当前预览接入 1,399 条文旅部公开村名录，并单独保留 9 个目的地的样例配套；规则整理每日安排，配置服务端密钥后由 DeepSeek 提供聊天回复和旅行建议。收藏、行程与反馈保存在当前浏览器。

文旅部名录截至 2022-12-07，提供名称、地区与批次，2026-09-26 导入。配套与坐标待补充；纯名录选择生成到访草稿。英文地名使用拼音辅助检索。样例商家、价格及营业状态未经核实，摄影仅作氛围示意。

让失败仍有下一步

需求可在推荐前修正；返回修改偏好时保留仍然有效的选择；活动超出每日容量时进入“待安排的心愿”，避免默默丢失。保存、导出和重新打开使规划结果可以留存。

后端增加模型调用超时边界。模拟测试覆盖标签解析、所选数据库内容进入提示词、路线保存，以及无密钥、503、超时、空响应时的模板降级。

证据与边界

已完成非视觉的双语全流程测试、数据与编排测试、使用数据库及模型替身的后端契约测试。2026-09-27 已验证真实 DeepSeek 中文聊天与英文旅行建议。网站已部署至 Vercel，公开页面和云端 AI 调用检查通过；生产数据库联调及浏览器截图验收尚未完成。

TEAM PROJECT · AI + RURAL TOURISM MVP · 2026

From a countryside idea
to a trip you can shape.

SylvaPlan / 村小丫 addresses fragmented rural travel information and the gap between preferences and specific experiences. The workspace connects requirements, destination matching, activity and hospitality choices, and itinerary generation.

Describe → Refine → Choose villages & experiences → Plan each day → Save & reflect

Design around the planning task

This interface update takes its layout reference from the Mindtrip workspace screenshot supplied by the project owner: persistent navigation, a central conversation and planning pane, and a map alongside. Chinese and English interfaces preserve inputs, selections and original user text.

The map shows approximate city areas. Verified village coordinates are not available, so these markers are not village locations or navigation instructions.

Two modes, one planning flow

  • Database and model mode: The original Express / MySQL backend retains sessions, database matching, selected dining, stays and activities, DeepSeek tag parsing and route generation. Template routes provide a fallback when the model is unavailable.
  • Easy preview mode: This preview combines 1,399 public MCT directory records with 9 separately labeled sample destinations and scheduling rules. With a server-side key, DeepSeek provides chat replies and travel advice. Favorites, itineraries and feedback stay in the current browser.

The MCT directory provides names, regions and batches, with a 2022-12-07 cutoff; imported on 2026-09-26. Amenities and coordinates remain missing. Directory-only plans are visit drafts. English place labels use pinyin for search. Sample businesses, prices and opening hours remain unverified; sample photography is illustrative.

A next step when something fails

Recognized requirements remain editable. Valid selections survive preference revisions. Choices exceeding daily capacity stay on a visible pending list. Trips can be saved, exported and reopened.

Time limits were added to model calls. Tests with database and provider doubles cover requirement tags, selected records in prompts, route persistence, and template fallback for missing credentials, HTTP 503, timeouts and empty responses.

Evidence and limits

Nonvisual bilingual journey tests, scheduling checks and backend contract tests have passed. Live DeepSeek Chinese chat and English travel advice passed on 2026-09-27. Production database integration, and browser screenshot acceptance remain unverified. This site is live on Vercel; public page access and cloud AI calls have passed smoke checks.
